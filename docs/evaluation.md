Each fixture needs question, declared environment, permitted data destinations, official original passages, mandatory facts and prohibited claims, mandatory documents/objects and source timestamps/hashes. A functional expert reviews FI/CO/MM/SD; an ABAP/RAP expert reviews development cases. Cases 12–14/17–19 are honest B0 coverage tests, not a claim to implement B1.

Compare A (base Claude, same evidence permissions/security), B0-direct (official services with approved controls) and B0-gateway (this implementation). Do not run an unguarded direct server with private data. Same model/settings/task/source snapshots/budget, separate cold/warm caches and new/follow-up sessions. Use a few cases for setup tuning, freeze the remaining cases before evaluation. Record version and tool schemas; remote content can change. A recorded replay isolates retrieval/Hook effects but is not live availability evidence.

Record correctness, product/release suitability, exact errors, document/object recall, unsupported claims, appropriate vs needless abstention, tool/failed/retry counts, wall time, all input/cache-write/cache-read/output tokens and actual cost including failed attempts. Do not infer tokens from characters. Read terminal Claude result usage once per isolated run and reconcile with provider billing. Subscription utilization is not automatically cash savings.

The stdio integration report proves the Python transport and gateway, not model tool selection or final request content. Hook evidence counters prove events were observed, not that every claim is supported. Inspect approved model request payloads where possible; if unavailable record that limitation. Do not install a credential-capturing proxy or export private traces merely to obtain measurements.

`updatedToolOutput` is disabled: future canary tests need actual installed version schemas for text/binary Read, each Grep mode, Bash stdout/stderr/interrupted/background, MCP structured/text/error cases. Confirm invalid-schema fallback and inspect final model input, not just Hook stdout. It is outside the current savings claim.

Select only among candidates passing agreed correctness and security gates, then compare total cost including errors and unnecessary abstention. This 28-case pilot does not establish general SAP accuracy or a savings percentage.
